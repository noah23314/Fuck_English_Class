# 中国传统纹样资料汇编

**A Sourcebook of Chinese Traditional Motifs**

本仓库收录一份关于中国传统纹样的资料汇编，以「图必有意，意必吉祥」为中心，辑录故宫博物院、中国国家博物馆相关词条与藏品说明、《人民日报海外版》专题报道、地方博物馆科普文章及中新社专访等公开资料，并附英文术语对照与常见生词表。

## 内容结构

1. 总论：日用而不察的文明载体
2. 「图必有意，意必吉祥」：纹样的表意系统
3. 历史脉络：从陶器刻划到织绣满身
4. 代表纹样个案：云雷纹、回纹、缠枝纹、宝相花、莲花纹、龙/凤/海水江崖、蝙蝠与五福、几何吉祥纹、花果草木、十二章纹
5. 民间纹样：剪纸、年画与彩印花布
6. 跨文化：吸收、融合与中国化
7. 当代转化：从博物馆到设计
8. 图版目录与版权说明
9. 引用资料（文中上标编号可直接跳转原文）
